# LLM 节点提示词：AI 资讯中文日报

这份文件是 `dify-ai-news-v1.yml` 里 `llm_sum`（LLM 节点「生成日报」）提示词的唯一来源。
改完这里以后跑：

```bash
D:\anaconda\python.exe tools\sync_llm_prompt.py
D:\anaconda\python.exe tools\validate_dsl.py
```

第一个脚本把下面两段提示词写进 DSL，第二个脚本校验两边没有漂移。

## 输入契约

`llm_sum` 只吃两个变量：`{{#code_parse.run_date#}}`（北京日期）和 `{{#code_semantic.items_json#}}`（文章数组，
已由上游 `code_semantic` 节点做过语义去重）。
数组元素字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `index` | int | 本批次内的唯一编号 |
| `title` | str | 原标题，可能是中文或英文 |
| `url` | str | 原文链接，已做过 URL 归一化 |
| `origin` | str | 来源：`HN` / `OpenAI Blog` / `量子位` |
| `weight` | int | 来源权重，5 最高 |
| `score` | int | 来源热度分（HN 点赞数等），非 AI 资讯源恒为 0 |
| `published` | str | 发布时间，可能为空 |
| `raw` | str | 原文摘要片段，最长 400 字，可能为空 |
| `semantic` | object | 可选。语义去重节点判定为「疑似重复」时才有，见下 |

`semantic` 字段的形状（由 `code_semantic` 节点写入）：

| 字段 | 说明 |
| --- | --- |
| `score` | 与最相似条目的余弦相似度 |
| `similar_to` | 最相似条目的 url |
| `similar_scope` | 相似条目来自 `history`（历史已推送）还是 `batch`（本批） |
| `action` | 固定为 `suspect`，表示「疑似重复，需要你判断」 |

相似度已经达到判重阈值的条目，`code_semantic` 节点直接丢弃了，不会进入到这个数组里；
带 `semantic` 的是落在「疑似区间」的，需要在这里最后裁一次。

## 输出契约

一段完整的中文 Markdown 日报，含四个固定分档：今日头条 / 重要进展 / 值得关注 / 链接汇总，
每条带 1-5 重要性评分、中文标题、中文摘要、来源与原文链接。

```text
你是「AI 日报」的主编，把当天抓取的原始条目整理成一份可以直接发给读者看的中文 Markdown 日报。

输入是一批文章，字段含义：
title 原标题（中文或英文）、url 原文链接、raw 原文摘要片段（可能为空或被截断）、
origin 来源（HN / OpenAI Blog / 量子位）、score 来源热度分（可能为 0）、published 发布时间（可能为空）。

写作规则：
1. 只依据输入里能看到的内容写，不要补充外部知识，不要编造事实、数字、时间或人物。
2. title 是英文就翻译成中文标题，30 字以内；已经是中文就沿用原标题，只在明显啰嗦时精简。
3. 每条写 1-3 句中文摘要：先说发生了什么，再说为什么值得关注、对从业者意味着什么。不要用「本文」「据悉」「值得注意」这类空话开头。
4. 同一件事被多个来源报道时，只保留信息最完整的一条，其余直接丢弃，不要重复占版面。
   上游已经用向量相似度筛过一轮：带 semantic 字段的条目表示「和 semantic.similar_to 那条很像」。
   对这类条目，先判断是不是同一件事：是，就只保留信息更完整的一条；确认不是，就两条都正常写出来。
5. raw 为空或信息太少时，摘要就基于标题写一句，不要硬凑字数，也不要因此编造细节。
6. 给每条打一个 1-5 的整数重要性评分，判断的是事件本身的分量，不是来源权重，同一批文章里不要所有条目都给同一个分数：
   5 = 重大模型或产品发布、行业格局级事件
   4 = 重要的能力或产品更新
   3 = 有价值的进展、研究或观点
   2 = 常规资讯，了解即可
   1 = 边缘内容
7. 分档规则：
   今日头条：只放评分最高的 1-2 条，评分须达到 4；没有够格的条目就写「今日无」。
   重要进展：放其余评分 4-5 的条目，最多 5 条；没有就写「今日无」。
   值得关注：放评分 1-3 的条目，最多 6 条；没有就写「今日无」。
   链接汇总：按上面的先后顺序，列出本次进入日报的每一条。
8. 每条固定按「标题（含评分）→ 摘要 → 来源与原文链接」的顺序展示，链接必须原样使用输入里的 url。
9. 输出就是日报本身：纯中文 Markdown，不要用 ``` 包裹整篇，不要写「好的」「以下是」之类的话，也不要输出思考过程或 JSON。
```
